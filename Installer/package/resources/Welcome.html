Rane SL 2 — Native CoreAudio HAL Driver

Version 1.0.0 • macOS Big Sur, Monterey, Ventura, Sonoma & Sequoia

Welcome to the modern user-space macOS driver installer for the Rane SL 2 USB 2.0 DJ Audio Interface. This package replaces the discontinued legacy Kernel Extension (.kext) with a native Apple Silicon & Intel CoreAudio HAL Plug-In.

What Will Be Installed:

  • SL2Device.driver — 4-Channel (4 In / 4 Out) 24-bit @ 44.1 / 48 kHz CoreAudio HAL Plug-In with Implicit Feedback clock sync.
  • SL2Api.framework — Universal bridge allowing Serato DJ Pro 2.5.5 to communicate with the SL 2 without a kernel extension.
  • SL 2 Control Panel — an app (in Applications) showing the SL 2's status, Phono / Line switch and latency, for switching Analog Thru per deck and choosing the sample rate; plus the sl2panel Terminal utility.

No Reduced Security or kext approval required: Because this driver runs 100% in user space via Apple's modern IOUSBHost framework, your Mac's security settings remain intact and no system reboot is required.
